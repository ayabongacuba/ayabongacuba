## Selected Projects

### [Grid Search & Route Planning](https://github.com/ayabongacuba/gridsearch-project)

A C++17 project exploring pathfinding and route optimisation.

- Implementations of DFS, BFS, Dijkstra and A*.
- Floyd–Warshall and waypoint cost matrices.
- Travelling Salesperson Problem optimisation.
- Testing, benchmarking and interactive visualisations.

**Concepts explored:** Graph algorithms, algorithm complexity, search strategies and optimisation.

A C++ command-line application demonstrating object-oriented programming and multi-file compilation.

- Compilation and linking with g++.

**Concepts explored:** C++ fundamentals, object-oriented programming and software organisation.
